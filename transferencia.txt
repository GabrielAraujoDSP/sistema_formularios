TRANSFERÊNCIA PARA OUTRA CONTA GOOGLE
======================================
Este guia explica como mover todo o sistema (planilha, Drive e Apps Script)
para uma conta Google diferente.

────────────────────────────────────────────────────────────
PARTE 1 — NA CONTA NOVA (Google que vai receber o sistema)
────────────────────────────────────────────────────────────

PASSO 1 — Criar a planilha
  1. Acesse sheets.google.com na conta nova
  2. Crie uma planilha em branco (qualquer nome, ex: "Fichas Locação")
  3. Copie o ID da planilha da URL:
     Ex: docs.google.com/spreadsheets/d/  >>ESTE-TRECHO-É-O-ID<<  /edit
  4. Guarde esse ID — será o novo SHEET_ID

PASSO 2 — Criar a pasta no Drive
  1. Acesse drive.google.com na conta nova
  2. Crie uma pasta (qualquer nome, ex: "Fichas Locação - Arquivos")
  3. Abra a pasta e copie o ID da URL:
     Ex: drive.google.com/drive/folders/  >>ESTE-TRECHO-É-O-ID<<
  4. Guarde esse ID — será o novo FOLDER_ID

PASSO 3 — Criar o Apps Script
  1. Acesse script.google.com na conta nova
  2. Clique em "Novo projeto"
  3. Apague o código padrão e cole TODO o conteúdo do arquivo backend.gs
  4. No topo do código, atualize as duas linhas:
       var SHEET_ID  = 'COLE-AQUI-O-NOVO-SHEET-ID';
       var FOLDER_ID = 'COLE-AQUI-O-NOVO-FOLDER-ID';
  5. Salve (Ctrl+S)

PASSO 4 — Criar o administrador inicial
  1. Ainda no Apps Script, localize a função configurarPrimeiroAdmin
  2. Preencha ADMIN_EMAIL e ADMIN_SENHA com os dados do novo admin
  3. No menu superior clique em "Executar" → selecione configurarPrimeiroAdmin → Executar
  4. Confirme o acesso quando solicitado
  5. Veja o resultado em "Execuções" ou Visualizar → Registros
  6. Apague os valores de ADMIN_EMAIL e ADMIN_SENHA do código e salve

PASSO 5 — Publicar o Apps Script como App da Web
  1. Clique em "Implantar" → "Nova implantação"
  2. Tipo: App da Web
  3. Executar como: Eu (seu e-mail da conta nova)
  4. Quem tem acesso: Qualquer pessoa
  5. Clique em "Implantar" e confirme as permissões
  6. Copie a URL gerada (termina em /exec) — esta é a NOVA URL

────────────────────────────────────────────────────────────
PARTE 2 — NO CÓDIGO DO PROJETO (VS Code / editor)
────────────────────────────────────────────────────────────

PASSO 6 — Atualizar a URL nos três arquivos HTML
  Abra cada arquivo abaixo e substitua a URL antiga pela NOVA URL:

  formulario.html
    Procure por: const APPS_SCRIPT_URL = '...'
    Troque pelo valor da nova URL

  painel.html
    Procure por: const APPS_SCRIPT_URL = '...'
    Troque pelo valor da nova URL

  dashboard.html
    Procure por: const APPS_SCRIPT_URL = '...'
    Troque pelo valor da nova URL

PASSO 7 — Publicar as alterações
  1. git add formulario.html painel.html dashboard.html
  2. git commit -m "transferencia para nova conta google"
  3. git push
  4. Aguardar Netlify republicar (menos de 1 minuto)

────────────────────────────────────────────────────────────
PARTE 3 — DADOS ANTIGOS (opcional)
────────────────────────────────────────────────────────────

As fichas já existentes ficam na conta antiga. Se quiser migrar:

  Planilha:
    - Na conta antiga, abra a planilha → Arquivo → Fazer download → .xlsx
    - Na conta nova, importe os dados para a aba "Fichas"
    - Atenção: a primeira linha deve ser o cabeçalho exato (não apague)

  Arquivos do Drive:
    - Os links de arquivos antigos (documentos, comprovantes) continuarão
      funcionando enquanto a conta antiga existir e os arquivos não forem
      apagados de lá. Não é necessário mover os arquivos se a conta antiga
      ainda ficar ativa.
    - Se quiser mover: selecione todos na pasta antiga →
      clique com botão direito → Mover para → escolha a nova conta
      (requer que as duas contas estejam logadas no mesmo navegador)

────────────────────────────────────────────────────────────
RESUMO DOS ITENS QUE MUDAM
────────────────────────────────────────────────────────────

  backend.gs   → SHEET_ID e FOLDER_ID (linhas 26 e 27)
  formulario.html → APPS_SCRIPT_URL
  painel.html     → APPS_SCRIPT_URL
  dashboard.html  → APPS_SCRIPT_URL

Nenhuma outra parte do sistema precisa ser alterada.
